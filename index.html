WhatsAppArchive Collector

A personal, single-user tool for keeping daily exports of recent WhatsApp messages in the user's private Google Drive.

How it works

After the user links a WhatsApp device, a collector on the user's Google Cloud virtual machine processes message updates and prepares daily exports. When the user authorizes Google Drive, the tool creates its own folder in the user's My Drive and uploads those exports there.

The Google connection requests only the drive.file scope. This lets the app create and manage files it creates; it does not give it general access to the user's other Drive files.

Access and control

The app is for its owner only. Exports are intended to remain private in the owner's Drive and are not published on this website. The owner can revoke Google access in their Google Account, unlink the WhatsApp device, and remove stored exports from Drive.

This website contains app information only. It does not host messages, exports, account credentials, or the collector's code.

Read the privacy policy and terms of use. For consent questions, use the support address shown on the Google authorization screen.
